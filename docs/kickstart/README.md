# AI-Native Project Kickstart Pattern Pack

This pack contains human-facing and agent-facing versions of the same operating methodology.

## Human-facing

`human/AI_NATIVE_PROJECT_PATTERN_ATLAS.html`

Self-contained HTML using inline SVG/CSS. Intended for:

- project kickoffs;
- team onboarding;
- architecture and delivery discussions;
- explaining the mental model behind the workflow.

## Agent-facing

`agent/AI_NATIVE_PROJECT_PATTERNS.md`

Normative operational specification covering:

- intent;
- required behaviour;
- anti-patterns;
- escalation and stop conditions;
- evidence and Git safety rules.

## Bootstrap checklist

`agent/NEW_PROJECT_KICKSTART.md`

A practical sequence for setting up the minimum governance needed before implementation.

## Included patterns

1. Baseline Specs + Current Repo Truth + Risk-Adaptive Delivery
2. Coherent Vertical Slice PR
3. Canonical Domain State → Derived Views
4. Evidence Integrity
5. Repository-Centric Durable Context
6. Separate Implementation Authority from Merge Authority
7. Fail-Closed VCS Operations
8. Integration ≠ Review ≠ Release
9. Freeze Accepted Areas
10. Route by Cognitive Dependency, Not File Ownership
